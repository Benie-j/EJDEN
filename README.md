# EJDEN

EJDEN est une application de gestion d'activité reconstruite avec Kotlin Multiplatform.

## Référence fonctionnelle

Le projet `EJDEN-app` constitue la référence fonctionnelle de l'application.

Cette nouvelle implémentation ne réinvente pas EJDEN.
Elle reconstruit progressivement ses fonctionnalités avec une architecture Kotlin Multiplatform destinée à Android et iOS.

## Architecture

- `shared/` : code commun Kotlin Multiplatform
- `androidApp/` : application Android
- iOS : intégration prévue via Xcode

## Principe

EJDEN-app = référence fonctionnelle.

EJDEN = nouvelle implémentation technique.
